Landing Page  for Burger King Belarus

Project Overview
A adaptive website designed to promote the promotional game and gather information about its duration, prizes, rules and winners
Client
Burger King Belarus
My role
UX UI Designer
Tools
Figma, Adobe Illustator, Adobe Photoshop
Project Goal
To create a website where users can easily access all the information about the Burger King Belarus promotional game and be encouraged to take part in it
Solutions
Analyze promotional websites from other companies to identify key patterns that ensure a seamless and engaging user experience. Use these insights to create a clear structure and visuals that motivate users to join the game

The Way I Worked

Research
• Analyzed promotional websites of major brands
• Identified key content sections
• Collected visual references
Planning
• Collected essential information about the game
• Created wireframes
• Built an interactive prototype
Design
• Prepared illustrations and graphics
• Designed an adaptive interface
• Incorporated client feedback
• Prepared the layout for development handoff

How It Works
To demonstrate the game mechanics, I used cards with illustrations and explanatory text. A prominent call-to-action button was added to enable users to quickly access the website or mobile app to make purchases
Prizes & Schedule
To encourage website visitors to join the game, I used bright cards in Burger King’s brand colors featuring real photos of the prizes. I also added a detailed calendar showing the dates and times of the draws
Winners Table
To make it easier and faster to search among winners, I added a filter that allows users to sort the winners’ table by draw date
Results
The landing page successfully supported the nationwide promotional game for Burger King Belarus. A total of 26,300 people participated, showing strong engagement driven by clear structure, bold visuals, and simple navigation.
In addition to the website, I designed the user account system where participants could view and manage their unique codes. The feature was implemented both on the website and inside the Burger King mobile app, ensuring a seamless and consistent experience across platforms.
