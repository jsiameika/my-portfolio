Multipage website  for a software development company

Project Overview
The goal of this project was to create a new adaptive website for the company Pangolin to effectively showcase its services and expertise. The website was designed to strengthen the brand’s online presence and attract new clients.
Client
Pangolin Development
My role
UX UI Designer
Tools
Figma, Webflow
Problem Statement
The main challenge was the absence of well-structured project cases and examples. It was also impossible to reuse content from the existing website, as it failed to represent the company’s experience and expertise.
Solutions
The solution was to build a new website structure and content from scratch, including clear service descriptions, detailed project cases, and a modern responsive design that highlights the company’s expertise.

The Way I Worked

Research
• Analyzed IT company websites
• Identified key content sections
• Studied competitors and market trends
• Collected visual references
Planning
• Mapped the structure of the existing website
• Identified user pain points and navigation issues
• Developed wireframes for pages
• Created an interactive prototype
Design
• Selected and prepared supporting images and graphics
• Developed a clean, modern, and adaptive interface
• Implemented feedback
Сolor palette

Homepage
The homepage presents the company’s core information, highlighting its approach, work principles, and technology stack. It also features a section with key project case studies to demonstrate expertise and results, along with a contact form that encourages potential clients to get in touch.
Portfolio Page
The Portfolio page showcases the company’s project cases in a clear and visually engaging way. Large cover images are used to capture attention, accompanied by project titles and brief client descriptions that highlight the company’s diverse experience and expertise.
Case Study Page
I developed a unified template for presenting the company’s case studies. Each case page includes key information about the work process — challenges, solutions, impact, tools and technologies — complemented by project visuals and a contact form for inquiries.
Results
The new website now clearly communicates PangolinDev’s core value and presents featured case studies from major clients such as Burger King, Lendflow, and Dodo Pizza, which strengthens credibility and highlights measurable business results.
Additionally, improved navigation, a refined content structure, and stronger visual hierarchy led to a 22% increase in average session duration.
